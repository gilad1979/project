# איקס עיגול

משחק איקס-עיגול לשני שחקנים בטרמינל, כתוב ב-Python.

## דרישות

- Python 3

אין תלויות חיצוניות.

## הרצה

```bash
python tictactoe.py
```

ב-Windows אפשר גם:

```bash
py tictactoe.py
```

## איך משחקים

1. שחקן `X` מתחיל, ואחריו שחקן `O`.
2. בכל תור מזינים **שורה ועמודה** מופרדים ברווח, במספרים מ-1 עד 3.
   - לדוגמה: `1 1` ממקם סימן בפינה השמאלית העליונה.
   - `2 2` ממקם סימן במרכז הלוח.
3. המשחק מסתיים בניצחון (שורה, עמודה או אלכסון) או בתיקו כשהלוח מלא.

קלט לא תקין (מחוץ לטווח, תא תפוס, או פורמט שגוי) יבקש ממך לנסות שוב.

## מבנה הפרויקט

```
tictactoe.py   # לוח, קלט שחקן, בדיקת ניצחון/תיקו ולולאת המשחק
```
